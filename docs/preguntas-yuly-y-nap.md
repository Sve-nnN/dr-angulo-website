## Parte 2. NAP: el dato que debe ser idéntico en todos lados

NAP es nombre, dirección y teléfono. Google compara esos tres datos entre todos los sitios donde aparece el doctor. Si en un lado dice "Av. El Derby 254" y en otro "Avenida El Derby 254 Of. 2403", Google puede leerlos como dos consultorios distintos y reparte la autoridad entre los dos en vez de sumarla.

**Regla simple: copiar y pegar exactamente este bloque en todos lados. Sin reescribir, sin abreviar, sin "mejorar".**

```
Nombre:     Dr. Juan Carlos Angulo Totesaut
Dirección:  Av. El Derby 254, piso 24, oficina 2403
            Edificio Lima Central Tower
            Santiago de Surco, Lima 15023, Perú
Teléfono:   +51 964 305 682
Sitio web:  https://drangulocolumna.com
```

Detalles que importan más de lo que parecen:

- **"Av."** abreviado, no "Avenida".
- **"Santiago de Surco"**, no "Surco" a secas.
- **El teléfono siempre con `+51`** y con los espacios tal cual están arriba.
- **La web siempre con `https://` y sin `www`.** El dominio correcto es `drangulocolumna.com`. Si en algún lado quedó `www.drangulocolumna.com`, funciona igual porque redirige solo, pero conviene dejar la versión sin `www`.

**Credenciales, cuando el formulario las pida:**


**Especialidades, siempre en este orden y con estas palabras:**

## Parte 4. Cómo saber si esto funcionó

Cuando estos enlaces estén publicados, se puede medir cuánta gente llega desde cada lugar. Para eso el enlace lleva una marca al final:

**Desde Instagram:**
```
https://drangulocolumna.com/?utm_source=instagram&utm_medium=social&utm_campaign=bio
```

**Desde la ficha de Google:**
```
https://drangulocolumna.com/?utm_source=google&utm_medium=organic&utm_campaign=gbp
```

**Desde Doctoralia:**
```
https://drangulocolumna.com/?utm_source=doctoralia&utm_medium=referral&utm_campaign=perfil
```

Esas marcas no cambian la página que ve el paciente, solo permiten distinguir de dónde vino. Se pegan en el campo de sitio web de cada perfil, en lugar del enlace simple.

Nota: para que esos datos se vean en un panel hace falta configurar Google Analytics, que todavía no está activo en el sitio. Los enlaces se pueden dejar puestos desde ya y empiezan a medir apenas se active.
